# 守望争锋 · 花村山城 (Hanamura Vanguard WebGL)

纯程序化 **WebGL2** 横版宽屏第一人称三英雄战术肉鸽（Roguelike）动作射击游戏。全项目无需外部模型、贴图或音频资源文件，所有建筑群落、第一人称英雄武器与手部骨骼、多足机关敌军、自定义 GLSL 特效着色器与合成音效均由代码实时生成。

## 核心特性

- **三名差异化可操控英雄**：
  - **岛田源氏（机动剑客）**：风魔手里剑三连投 / 扇形齐射、二段跳与爬墙、击杀重置冷却的「影 · 疾风斩」、拔刀弹反「闪 · 心眼招架」、终极拔刀「斩 · 龙神之剑」。
  - **岛田半藏（神射宗师）**：斜倾射法蓄力岚弓（完整第一人称押手与三弽弦手骨骼联动）、爬墙与空中跃步、「音 · 音障探测矢」透视增伤力场、「岚 · 五连弹射矢」、穿墙双生巨龙终极技。
  - **神机统帅（战术枪兵）**：高精度重型脉冲步枪、三联螺旋高爆飞弹、战术疾跑自动供弹、「生物力场」范围治疗增幅、「战术目镜」自动锁定。
- **立体三阶段山城战场**：包含宿场游艺街、双层侧窗一之门、大梵钟庭院与北回廊、二之丸枯山水及四重本丸天守道场，支持可破坏障子门、茶亭与木楯掩体。
- **生理学机关敌军与巨像首领**：多关节武士铁炮兵、屋脊激光狙击忍、六角能量重盾卫、四足交替对角步态机关蜘蛛、六足三脚架横行步态轰击蟹，以及多弱点部位破坏的八米荒神巨像。
- **零 GC 战斗循环与对象池架构**：投射物、弹壳、刀光、粒子、着色器冲击波及伤害跳字全部采用预分配对象池与 `InstancedMesh` 批处理。
- **自动化五维质量保障管线**：内置生成式几何共面 Z-Fighting 检测、程序化 PBR 贴图校验、渲染批处理性能预算、角色状态机与波次数值回归测试。

## 快速开始

### 环境要求

- Node.js `>= 20`

### 安装与运行

```bash
# 安装依赖
npm install

# 启动本地开发服务器 (默认 http://localhost:3000)
npm run dev
```

### 构建与测试

```bash
# 运行核心规则与五维自动化 QA 回归测试
npm test

# TypeScript 类型检查
npm run lint

# 构建生产静态包 (输出至 dist/)
npm run build
```

## 键鼠与触屏操控

| 动作 | 键盘 / 鼠标 | 横屏触控 |
| --- | --- | --- |
| 移动 / 跳跃 / 爬墙 | `W` `A` `S` `D` / `Space` | 左半屏动态摇杆 / 右侧跳跃键 |
| 主武器 / 蓄力射击 | 鼠标左键 | 右下主开火键（支持按住滑动跟枪） |
| 副武器 / 取消拉弓 | 鼠标右键 | 副武器技能键 |
| 英雄战术技能 1 | `Shift` | 技能槽 1 |
| 英雄战术技能 2 | `E` | 技能槽 2 |
| 终极技能 | `Q` | 终极充能轮盘 |
| 快速近战 / 换弹 / 召唤首领 | `V` / `R` / `B` | 对应战术按键 |
